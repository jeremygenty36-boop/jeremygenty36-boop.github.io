# Portfolio de Jérémy Genty

Site statique (HTML, CSS, JavaScript sans bibliothèque) publié avec GitHub Pages : https://jeremygenty36-boop.github.io/

- `index.html` : version française ; `en.html` : version anglaise, générée par `outils/generer_en.py` à partir de `index.html` et du dictionnaire `outils/traduction_en.py` (à relancer après toute modification).
- `carte/` : copie du site de la carte interactive (dépôt https://github.com/jeremygenty36-boop/carte-extremes-climatiques).
- `documents/` : rapports, posters et CV en PDF ; `outils/resume/` : source LaTeX du résumé imprimable.

Pages non référencées par les moteurs de recherche (balise noindex, `robots.txt`).

Réalisé avec l'assistance de Claude (Anthropic) pour le code et la mise en page ; contenus et vérifications par l'auteur.
